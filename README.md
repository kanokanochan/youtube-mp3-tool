# YouTube → MP3 変換ツール

YouTube のリンクを貼ると MP3 にして保存する、Windows パソコン用のツールです。インストール不要で、自分のパソコンの中だけで動きます。

**ダウンロードと使い方 👉 https://kanokanochan.github.io/youtube-mp3-tool/**

## 仕組み

- zip を展開して `YouTube-mp3を起動.bat` を実行すると、ブラウザに変換画面が開きます。
- 初回だけ、必要な部品（Python / yt-dlp / FFmpeg / Deno、合計 約 270 MB）をそれぞれの公式配布元から自動で取得します。
- 変換はすべて自分のパソコンの中で行われます。
